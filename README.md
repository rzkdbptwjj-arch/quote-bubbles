# 말풍선 인용구

인용구, 출처, 태그를 저장하고 검색하는 GitHub Pages용 웹앱입니다.

## 기능

- 인용구와 출처 입력
- 태그 입력
- 말풍선 카드 미리보기
- 인용구, 출처, 태그 검색
- 태그 버튼으로 필터
- 수정과 삭제
- 백업 내보내기/가져오기

## GitHub Pages에 올리기

새 저장소를 만들고 이 폴더 안의 파일들을 저장소 맨 위에 올립니다.

- `index.html`
- `styles.css`
- `app.js`
- `manifest.webmanifest`
- `README.md`
- `assets` 폴더

그 다음 `Settings > Pages`에서 `Deploy from a branch`, `main`, `/root`를 선택하면 됩니다.
